    Identidade terminal instrumentado — plano de implementação¶

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Substituir a contradição "datasheet vs liquid glass" por um sistema visual único, verificável por teste, e corrigir os quatro bugs de UI confirmados na auditoria.

    Architecture: Uma regra de três camadas (folha opaca / o que paira / o que aciona) expressa em tokens CSS únicos, com teste estático que quebra a suíte se alguém voltar a usar literal ou !important. Os bugs são corrigidos na mesma PR, por decisão do operador.

    Tech Stack: Next.js 15 (App Router), CSS puro com custom properties, next/font/google, node --test com asserção estática sobre o código-fonte (padrão já usado em tests/*.test.mjs).

    Spec: docs/superpowers/specs/2026-09-23-identidade-terminal-design.md

    Global Constraints¶

    • Branch: design/identidade-terminal, criada de origin/main. Uma PR só.
    • Nenhuma feature nova. Sessão de correção e coesão.
    • Tokens de cor exatos: --papel #08090A, --tinta #ECEEEF, --tinta-media #A2A8AA, --tinta-fraca #868C8F, --tenue #4A4F51, --regua #2B2F31, --ambar #E8A33D, --ciano #4DD4E8, --carmim #E0584C.
    • Tokens de superfície exatos: --raio 16px, --raio-sm 10px, --vidro-blur blur(20px), --vidro-fundo rgba(255,255,255,.06), --vidro-borda rgba(255,255,255,.16).
    • Fontes: Archivo (títulos e corpo) + IBM Plex Mono (dado, medida, rótulo técnico). Ambas por next/font/google.
    • Piso absoluto de mono: 11px. Hoje há 8px e 9px.
    • Proibido: text-shadow decorativo, scanlines, clip-path ornamental, animação que não comunique estado real.
    • Estado nunca é comunicado só por cor — sempre acompanha palavra.
    • npm test e npx tsc --noEmit verdes antes de cada commit.
