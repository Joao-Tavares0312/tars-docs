    TARS¶

    Uma plataforma para configurar, testar e operar assistentes conversacionais com controle sobre cada bot, canal e dado.

    O TARS reúne uma página pública, uma experiência de ensaio local no navegador e um painel autenticado para administrar bots. A aplicação web coordena configurações, documentos, canais, histórico e operação; a resposta do bot é produzida por um dos provedores configurados pelo operador.

    Sobre custo

    O código não adiciona serviços pagos obrigatórios. Hospedar a aplicação, banco e integrações depende dos planos e limites escolhidos pelo proprietário. Provedores externos podem alterar suas cotas gratuitas; confira os limites atuais antes de habilitar uso real. O ensaio local roda no navegador e não precisa de provedor de inferência.

    Mapa do sistema¶

    flowchart LR
  visitante["Visitante"] --> canal["Telegram ou Webchat"]
  canal --> api["Rotas Next.js"]
  api --> regra["Autorização, regras e cotas"]
  regra --> contexto["Histórico e base publicada"]
  contexto --> provedor["Provedor configurado"]
  provedor --> resposta["Resposta, feedback e telemetria"]
  painel["Operador autenticado"] --> api
  api --> banco["PostgreSQL"]

    O painel e os canais usam rotas distintas. As rotas administrativas exigem sessão e permissão por instância; as rotas públicas de Webchat e webhook validam, respectivamente, origem e segredo.
